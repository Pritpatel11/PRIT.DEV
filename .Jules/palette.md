## 2026-10-16 - Adding Accessible Labels to Forms
**Learning:** In futuristic or highly stylized applications, basic accessibility features like explicitly linking labels to inputs via `htmlFor` and `id` are often overlooked. Relying purely on visual layout (like block positioning) without these explicit semantic connections negatively impacts screen readers and reduces the click area for users, creating poor keyboard accessibility and an inconsistent UX.
**Action:** Always ensure that stylized UI forms use semantic HTML correctly by adding `htmlFor` and `id` attributes to explicitly link labels and inputs. Furthermore, applying utility classes like `cursor-pointer` to explicitly linked labels provides immediate visual feedback that the label is interactive, improving standard usability.
